BASE6 Girls PG Website
==============

A responsive static portfolio/marketing website for BASE6 girls-only PG accommodation in one 3BHK flat. Room prices vary based on the room and its attached or common washroom arrangement.

Included:
- index.html
- assets/base6-room-wide.jpeg
- assets/base6-room-twin.jpeg

Open index.html in a browser to preview.

Owner details are intentionally placeholders because names/backgrounds/photos were not supplied. Replace the two owner cards in index.html when those details are available.

To add more room/facility photos:
1. Put the images inside assets/
2. Add <img> elements to the gallery in index.html.

The Google Maps button uses a search URL based on the supplied address; verify the exact pin/address before publishing.
